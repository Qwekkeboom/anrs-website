# Website ANRS — Ain't No Rocket Science

Static, bilingual (Dutch/English) website for the band **ANRS**.

## Structure

```
index.html          # Dutch (default)
en/index.html       # English
404.html            # Custom 404 (served by GitHub Pages)
css/styles.css
js/main.js          # Mobile nav toggle only
assets/logo.png
robots.txt
sitemap.xml
.nojekyll           # Serve files as-is, skip Jekyll
```
